拍摄于 2026-11-09，macOS、VS Code 1.143.1、Code Atelier 1.3.0。使用独立的演示 Profile，内容全部来自仓库原创示例；图片为实际界面截图。

复现方式：安装 Release VSIX，打开 `examples/studio-guide` 文件夹，选择主题 **纸页 · Claude**，合并 `config/writing.settings.json` 中需要的偏好，运行 **纸页：进入／退出阅读模式**。为留出展示空间，演示 Profile 隐藏了左右侧栏与活动栏、关闭面包屑、采用单标签显示；这些是 VS Code 自带的布局选项。

编辑器字号 17px、行高 32px，窗口缩放为 0；代码使用 VS Code 默认字号。独立看图截图来自 Chrome，浏览器页面缩放为 75%。Mac 使用系统字体；Windows 的字体回退可能带来少量差异。未使用私人书稿或账号内容。
