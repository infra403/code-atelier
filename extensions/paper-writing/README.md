# 纸页 · Claude 写作与标记

保留原来的 Claude 暖白主题。编辑器工具栏：

- **B**：加粗，再次点击取消。
- **A**：直接应用已配置的文字色；同色再次点击取消。菜单和悬停提示显示当前色名，图标底部色条显示实际颜色。
- **荧光笔**：直接应用已配置的高亮色；同色再次点击取消。菜单、悬停提示和底部色条随配色设置自动更新。
- **配色按钮**（色板图标）：选择一次文字色或荧光笔色并永久记住，不修改正文。
- **Aa**：斜体、下划线、删除线、恢复默认文字色、清除高亮。

在左侧源文本中选中文字后点按钮，右侧预览实时显示。一次选同一源代码行内的文字，自动换行不受影响；⌘Z 撤销。已有的黄色高亮也带圆角和两侧留白。

文字颜色：陶土橙、松叶绿、墨水蓝、烟紫、酒红、石墨灰。
高亮颜色：奶油黄、杏桃橙、鼠尾草绿、雾蓝、淡薰衣草、玫瑰粉。

也可以在 VS Code 设置中搜索 `paperWriting`，设置 `paperWriting.textColor` 和 `paperWriting.highlightColor`。偏好保存在用户设置中，重启后保留。

## 图表

使用当前 VS Code 内置的 Mermaid 渲染器。旧的 `bierner.markdown-mermaid` 已停用，避免两个渲染器争用同一张图。图表采用暖白背景、陶土色线条与圆角节点，保留缩放、平移和重置按钮。未修改书稿中的 Mermaid 内容。

## 安装与维护

本扩展随 [VS Code 配置仓库](https://github.com/infra403/vscode-claude-dev-setup) 提供；使用根目录安装脚本，或通过“扩展：从 VSIX 安装”选择 `dist/paper-writing-1.1.0.vsix`。

源代码、调色板和图标均包含在仓库中。只对 Markdown 选区进行标记；支持撤销。颜色与高亮使用内联 HTML，需要支持 HTML 的 Markdown 预览器。
