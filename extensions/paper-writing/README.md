# Code Atelier · 编辑器工坊

VS Code 的外观与工作体验工具箱。当前扩展提供暖白主题、Markdown 标记、书架导航和图表阅读；更多界面美化将持续迭代。

## 一键阅读模式（1.2.0）

点击工具栏“进入／退出阅读模式”：自动左侧划词、右侧阅读，保留原来的标记按钮。

通过“纸页：添加书库”选择电子书所在文件夹。预览页顶提供“上一章／目录／下一章／切换书籍”，支持 README 目录内多层分册连续阅读。底部状态栏支持搜索章节和书籍，并记住每本书上次打开的章节。

阅读模式左侧默认占 40%，可用 `paperWriting.readingEditorRatio` 调整。再次点击可恢复原有分栏布局。书架只读取文件；导航不会写入书稿正文。

保留原来的 Claude 暖白主题。编辑器工具栏：

- **B**：加粗，再次点击取消。
- **A**：直接应用已配置的文字色；同色再次点击取消。菜单和悬停提示显示当前色名，图标底部色条显示实际颜色。
- **荧光笔**：直接应用已配置的高亮色；同色再次点击取消。菜单、悬停提示和底部色条随配色设置自动更新。
- **配色按钮**（色板图标）：选择一次文字色或荧光笔色并永久记住，不修改正文。
- **Aa**：斜体、下划线、删除线、恢复默认文字色、清除高亮。

在左侧源文本中选中文字后点按钮，右侧预览实时显示。一次选同一源代码行内的文字，自动换行不受影响；⌘Z 撤销。已有的黄色高亮也带圆角和两侧留白。

文字颜色：陶土橙、松叶绿、墨水蓝、烟紫、酒红、石墨灰。
高亮颜色：奶油黄、杏桃橙、鼠尾草绿、雾蓝、淡薰衣草、玫瑰粉。

也可以在 VS Code 设置中搜索 `paperWriting`，设置 `paperWriting.textColor` 和 `paperWriting.highlightColor`。偏好保存在用户设置中，重启后保留。

## 图表

使用当前 VS Code 内置的 Mermaid 渲染器。如果安装了 `bierner.markdown-mermaid` 且出现冲突，请停用重复渲染器。图表采用暖白背景、陶土色线条与圆角节点，保留缩放、平移和重置按钮。未修改书稿中的 Mermaid 内容。

图表上方新增 **放大阅读**。打开后按可读字号显示原始矢量图，支持拖动平移、滚轮或 ± 缩放、「全图」与「清晰字号」切换；按 Esc / 关闭返回原阅读位置。长图不再需要反复点缩放按钮才能看清文字。

## 安装与维护

本扩展随 [VS Code 配置仓库](https://github.com/infra403/code-atelier) 提供；使用根目录安装脚本，或通过“扩展：从 VSIX 安装”选择 `dist/paper-writing-1.3.0.vsix`。

源代码、调色板和图标均包含在仓库中。只对 Markdown 选区进行标记；支持撤销。颜色与高亮使用内联 HTML，需要支持 HTML 的 Markdown 预览器。

### 图片单独全屏（鼠标操作）

图表旁和「放大阅读」工具栏均有 **图片单独全屏 ↗**。点击后在本机默认浏览器打开独立矢量看图页，再点 **图片单独全屏 ⛶**，屏幕只保留图表，VS Code 界面和浏览器标签栏都会隐藏。

- 鼠标滚轮缩放，按住左键拖动；「全图」查看完整关系，「清晰字号」恢复阅读尺寸。
- 全屏时操作栏会自动隐藏；移动鼠标显示，再点 **退出图片全屏**，也可按 Esc。
- 保留原图的颜色和矢量文字；原来的双栏和书稿不受影响。图表只在本机处理，不上传外部服务。
- 如需同时保留 VS Code 工具栏，预览标签栏另有「预览铺满屏幕」按钮。再次点击退出会恢复原双栏。
